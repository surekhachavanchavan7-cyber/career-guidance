# Career & College Guidance Portal

## 📌 Project Overview

The **Career & College Guidance Portal** is a frontend-based web application designed to help students explore career options, suitable courses, entrance exams, and colleges based on their interests.  
The project provides an interactive dashboard where users can assess career paths, view college listings, and explore detailed college information.

This project is developed as part of an **internship submission** and focuses on usability, clarity, and structured guidance for students.

---

## 🎯 Features

- Career exploration using interactive career cards
- Career assessment quiz with recommendations
- Course-wise college filtering
- College listing with images and key details
- Individual college details page
- LocalStorage-based data handling
- Responsive and user-friendly UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser LocalStorage

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Use **Live Server** or open `index.html` directly in the browser.
4. No additional setup is required.

---

## 🔐 Credentials

This project does **not require any login credentials**.

Users can directly access all features including:

- Career exploration
- Career assessment quiz
- College listings
- College details page

No username or password is required as this is a frontend-only project using LocalStorage.

---

## 📌 Notes

- College and course data are stored in browser LocalStorage.
- The project does not use backend or database services.
- Designed for educational and demonstration purposes.
